THE RULE
One canonical place, one page. The incoming context may add one line under the byline, re-rank the pair, and change the first verb. It may not change a fact, a sentence, a face, or the plate. Back always returns to the exact origin and its scroll. Opening implies nothing.
WHAT IS ALREADY TRUE IN CODE
The rebuilt page reads one presentation for every route; the ranker takes an explicit viewer context (near, hour, distance); the relationship line carries an active Plan title; the situation summary is request-scoped. The context line and the arrangement-first verb are design-only.
