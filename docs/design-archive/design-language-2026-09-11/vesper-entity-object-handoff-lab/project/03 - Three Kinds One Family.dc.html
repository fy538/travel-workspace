WHAT CHANGES BY KIND, AND ONLY THIS
The plate (your photo or a permitted one for an entity; Vesper’s map for a container or a spot), the source of current truth (a listing; time and light; nothing), and the verbs (Ask + Leave for someone; Open the map + Ask + Read; Keep + Reply). Everything else is the same page in the same order.
THE KIND TEST
Opens and deserves a verdict: entity. Contains others: container. Made by a person with no listing behind it: spot. A neighbourhood is both entity and container, and always was.
THE SPOT IS THE NEW ADMISSION PATH
Self-sourced coordinates, a typed name, one line; owner-private until granted; promoted to the entity it sits at when a resolution matches. A separate slice from provider resolution, and pins need it first.
