The selected designs, now on shared construction

This pass was consolidation and obvious cleanup, not optimization. Every selected specimen compared in the workbench now appears three ways with the same content and width: as drawn, carried onto the kernel by a live port that keeps its geometry, and — where a shared component is proposed — rebuilt from that component. Where the kernel lacks an exact value the value is kept and named as a proposed role or token. The eight v0.1 checkpoint proposals are no longer questions; §17.4 disposes of them, applied below.
