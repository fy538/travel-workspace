Two waterfronts, two different thresholds
Sorrento’s town and marina are close on a map but separated by elevation and transfer. Red Hook is comparatively flat; its threshold is the continuity of the network that reaches it.
DISTANCE Short physical distance can still conceal a hard transition.
DEPENDENCY Sorrento’s candidate constraint is vertical transfer and ferry sequence. Red Hook’s is network continuity and schedule.
FALLBACK Saturday remains flexible only if the return does not depend on the same fixed edge as the arrival.
