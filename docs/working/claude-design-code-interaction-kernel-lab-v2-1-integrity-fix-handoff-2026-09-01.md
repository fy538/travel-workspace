# Claude Design + Claude Code Handoff — Interaction Kernel Lab V2.1 Integrity Fix

## 0. Executive correction

Continue the existing project and repair it in place:

- **Project:** `Vesper — Interaction Kernel Lab`
- **Project ID:** `6dd8b450-9686-4814-8db9-667f0e99db2c`
- **Durable link:** <https://claude.ai/design/p/6dd8b450-9686-4814-8db9-667f0e99db2c>
- **Audited export:** `~/Downloads/vesper-interaction-kernel-lab/project/`

Do not create another project. Preserve V1 and the V2.0 record. Add a V2.1
correction layer.

V2.0 is a strong internal hypothesis demonstration and a materially better
prototype substrate. It is **not yet a controlled participant study**. Its
routes are clickable, its runtime is stable, and its visual treatment is
coherent, but several routes invent or discard user truth. The treatment
comparisons also begin at unequal semantic checkpoints.

The V2.1 objective is:

> Make every visible result causally faithful to what the person actually
> supplied or chose, make treatment comparisons begin from equivalent semantic
> state, and make the project honest about what is drawn, exercised, or still
> blocked.

This is not a visual-language round, a production implementation, a universal
object architecture, or a new product thesis. It is an integrity correction.

Every new or materially changed research page retains:

> **EXPLORATION · INTERACTION RESEARCH · NOT CANON · NOT PRODUCTION**

Participant mode must contain none of that research language, visibly or in
its accessible announcements.

```text

comparison integrity treatments differ only in the declared factor
measurement integrity traces describe the work actually performed
```

## 4. P0 findings — must fix before founder walkthrough

  pacing decision.

  buffer—the breathing-room delta the person never selected.

  breathing-room shape, losing the gallery and tighter-changeover choice.

Required correction:

- The current prospective shape must carry forward exactly through comparison.
- If pace remains open, choosing a room keeps pace open.
- If `breathing_room` was selected, its dinner/buffer persists.

  preferred branch.

### P0.2 A2 changes Corner Note into Blue Aster

Current failure:

- Hybrid `Keep it anyway` does the same.

Required correction:

### P1.2 Deterministic language edges silently accept divergence

Current behavior routes any non-empty utterance to the scripted next state.
This is acceptable for deterministic capture, not participant evidence about
language.

Implement explicit modes:

- **capture:** seeded canonical utterance may advance deterministically;
- **founder/research:** divergent text fails closed and records the unresolved
  expression;

  resolver exists, unless the study is explicitly limited to recognized intent
  phrases and reported as such.

Minimum fail-closed behavior:

- supported fixture intents have a small declared recognizer;
- unrecognized text stays on the same state;
- no owner truth changes;
- trace records `result: unresolved` and the semantic-intent class, not the raw
  private text unless the research protocol explicitly authorizes local
  collection; and
- research mode shows why it failed without exposing parser mechanics to the
  participant.

Do not pretend a keyword recognizer is evidence about production AI quality.
