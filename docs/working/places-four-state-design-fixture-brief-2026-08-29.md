# Places Four-State Design Fixture Brief

## Decision

Compose four full-scroll mobile Places screens from one continuous evidence
world:

1. **World Field** — New York, no Place selected;
2. **Place Focus** — Red Hook selected;
3. **Place Path** — Red Hook's network threshold compared with Sorrento's
   vertical marina threshold; and
4. **Live Reduction** — the Red Hook interval under current Saturday
   conditions and an existing dinner anchor.

This is a semantic fixture for a dedicated visual-design environment. It is
not production copy, a route recommendation, a commitment, or authorization to
implement the app.

The four screens must feel like four states of one navigable encounter—not
four standalone concepts. The same scope, focal Place, map position, Sources,
selection, and return path must visibly persist as the person moves through
them.

## 1. What the fixture must prove

The board should answer seven questions:

1. Can Places provide immediate value without opening with a prompt?
2. Can a substantial root avoid reading like an infinite content feed?
3. Can map and editorial composition behave as two views of the same world?
4. Can one Place become deep without becoming an encyclopedia?
5. Can a prior trip improve a present possibility without taking over the
   page?
6. Can an authorized human trace behave as evidence rather than social-feed
   activity?
7. Can live conditions reduce the same experience toward action without
   making Places feel like a separate trip-planning product?

The board fails if it only demonstrates attractive cards.

## 2. Evidence world

### 2.1 Observed founder evidence

The following may be treated as user-authored or user-supplied evidence in the
fixture:

- the user returned to New York after traveling through Nice, Sorrento,
  southern Italy, and Rome;
- the user explicitly noticed Sorrento's cliffs;
- questions arose around town versus marina, luggage, ferry check-in,
  vertical movement, and walking into town;
- ferry tickets, hotel evidence, photographs, and other travel Artifacts were
  supplied to Vesper;
- the user is interested in a present New York weekend rather than a Home or
  Places experience dominated by a Europe recap; and
- a recent trip should matter only when it creates current understanding,
  capability, relationship, or possibility.

These facts do not prove that the user loved the coast, prefers ferries,
dislikes hills, misses vacation, needs recovery, or has a travel personality.

### 2.2 Fixture assumptions

The following are synthetic but admissible for visual testing:

- Saturday from **2:00–8:00 PM** is explicitly open;
- an existing dinner anchor begins at **8:15 PM** near a viable return
  corridor;
- Red Hook is currently reachable by one fixed or schedule-sensitive approach
  and at least one flexible land return;
- current weather and access conditions permit the route;
- Brooklyn Bridge Park and Governors Island are alternative waterfront scopes
  with materially different access structures;
- the user has one saved Place in Red Hook but no confirmed visit record; and
- an authorized fixture friend, **Maya**, previously shared one bounded Red
  Hook movement note with the user.

These are not production claims. Replace them with current authoritative facts
or remove the affected composition in any implementation.

### 2.3 Required production authorities

The production version would require:

- current ferry, subway, bus, traffic, and walking-route sources;
- current weather, heat, precipitation, and daylight sources where material;
- verified hours, reservation, event, and accessibility facts;
- place geometry and topography;
- exact hotel, marina, route, and ticket evidence from the user's governed
  Sources;
- author, audience, may-use, may-name, and revocation state for Maya's note;
- current calendar or commitment truth for the open interval and dinner; and
- correction and Outcome evidence for any claim about what worked before.

### 2.4 Known-to-person posture

| Claim or cue | Posture |
| --- | --- |
| “Sorrento has cliffs” | Explicitly supplied by the user; do not present as Vesper's discovery |
| The actual Sorrento town–marina movement sequence | Partly supplied; may need reconstruction and correction |
| Physical distance differs from practical reachability | Vesper synthesis; must be supported and framed as a bounded distinction |
| Red Hook's current access structure | Current world fact; must be fresh |
| The Sorrento ↔ Red Hook threshold comparison | New Vesper contribution; analogy limit required |
| Saturday's composed interval | Generated possibility; not desired, saved, or committed until the user acts |
| Maya's movement note | Human-authored Source; use and naming depend on grants |

## 3. Continuity contract across all four screens

### 3.1 Persistent semantic state

Every frame carries:

```text
scope: New York
focal Place: none -> Red Hook -> Red Hook
origin: Places root or Home waterfront opening
interval: Saturday 2:00–8:00 PM when relevant
end constraint: dinner at 8:15 PM
selected Sources: Sorrento movement evidence + current New York world truth
human Source: Maya note when authorized
return destination: exact prior state and scroll position
```

### 3.2 Persistent chrome

Use one compact top system throughout:

- scope handle: `NEW YORK` or `RED HOOK`;
- contextual subline only when needed: `Saturday · 2–8 PM`;
- search affordance;
- map/composition transformation affordance;
- profile or personal-scope affordance only if it already belongs to the
  current design system; and
- back control inside Place Focus, Place Path, and Live Reduction.

Do not add state tabs labeled `World`, `Place`, `Path`, or `Live`. Those are
design and system terms, not consumer navigation.

### 3.3 Transition rules

| Origin | Gesture | Destination | Preserved state |
| --- | --- | --- | --- |
| World Field | Tap Red Hook lead, row, or pin | Place Focus | New York scope, selected Place, map viewport, originating reason |
| Place Focus | Tap `Why getting there changes the afternoon` | Place Path | Red Hook identity, Sorrento Source, current interval if present |
| Place Path | Tap current Saturday possibility | Live Reduction | comparison, route candidates, end constraint, evidence |
| Home | Tap compact waterfront proposition | Live Reduction or Place Path directly | exact Home proposition, interval, selected Sources, return to Home |
| Any Places state | Switch map/composition | Same state, alternate medium | selection, filters, path, viewport, scroll anchor |
| Any deeper state | Back | Exact origin | position and followed path remain visible |

## 4. Frame 1 — World Field

### 4.1 Human posture

The person opens Places normally. They have not selected a Place and have not
asked a question.

The surface answers:

> **What is possible in the New York world I am looking at, and where should
> I look more closely?**

### 4.2 First screenful

#### Scope handle

```text
NEW YORK
Saturday · 2–8 PM open
```

The time line appears because the interval is explicit. It is not a question
or a calendar task.

#### Lead composition

```text
ONE WATERFRONT AFTERNOON, WITH TWO WAYS HOME

Red Hook is slower to enter than the map distance suggests. A scheduled
approach can give the afternoon a beginning; a land return keeps the end
flexible before dinner.

2:20–7:40 PM · fixed start · flexible return
```

Lead medium:

- compact spatial field showing origin, scheduled approach, Red Hook,
  flexible return, and dinner anchor;
- map geometry and the proposition must be understandable together;
- the map is evidence, not a decorative thumbnail.

Primary door:

```text
Open Red Hook
```

The whole lead is tappable. The label clarifies destination; it does not
duplicate a nested action.

### 4.3 Standard branches

Show three and only three:

#### Red Hook — lead Place

```text
RED HOOK
Harbor first · scheduled way in · flexible way out
```

Use prominent orientation with image or map above. This is the selected lead,
not a raised recommendation card.

#### Brooklyn Bridge Park — alternative structure

```text
BROOKLYN BRIDGE PARK
Continuous land access · easiest to shorten
```

Use compact orientation. This branch exists because its fallback structure is
different, not because it is another waterfront.

#### Governors Island — alternative structure

```text
GOVERNORS ISLAND
The crossing is the experience · the return is least flexible
```

Use compact orientation and an explicit schedule caveat. Remove if current
service or the interval does not support it.

### 4.4 One returned-understanding unit

```text
DISTANCE IS NOT THE WHOLE ARRIVAL

Your Sorrento evidence separates four things maps often collapse: distance,
elevation, transfer path, and practical reachability. New York's waterfronts
separate them differently.

Follow the threshold comparison →
```

This is the only Europe-derived unit in the World Field. It adds a distinction
and a path. It is not a trip recap.

### 4.5 Compact continuity doors

```text
Saved near the harbor · 1
Your New York waterfront map
Saturday plans and occasions
```

No numeric tally, relationship ladder, or `complete your profile` language.

### 4.6 Page end

End after the continuity doors. Do not add Reading, Events, From Your People,
Trending, More Nearby, or another generic shelf merely to fill the page.

### 4.7 Interaction annotations

- tapping any Red Hook expression selects the same Place Focus;
- tapping the map pin and the lead text produces the same selection;
- switching to full map keeps the three branches and their reasons;
- tapping the Sorrento-derived unit opens the Place Path with Red Hook focal;
- back from deeper states returns to this scroll position with Red Hook marked
  as followed.

## 5. Frame 2 — Place Focus

Identity, current read, relationship, human perspective, and horizon are
semantic roles for the composition. Do not expose them as five permanent
section labels or five equally weighted modules.

### 5.1 Human posture

Red Hook is selected from the World Field. The person is not yet committed to
Saturday's interval.

The surface answers:

> **What is Red Hook, what does it afford now, what is my relationship to it,
> and what is worth following from here?**

### 5.2 First screenful

#### Place identity

```text
RED HOOK
Brooklyn waterfront · harbor edge
```

Lead medium:

- place-scale map or evidence-bearing image;
- show relation to the rest of Brooklyn and the relevant access edges;
- do not default to a generic provider photograph.

#### Current read — verdict register

```text
THE ARRIVAL SHAPES THE AFTERNOON

Use the scheduled crossing to give the visit a clear beginning. Keep the land
return as the flexible edge; making both directions schedule-dependent would
turn the afternoon into timetable management.

Current basis · Saturday interval · service and route facts checked [[TIME]]
```

This is a fixture verdict. In production it renders only if current route and
service evidence supports every clause.

### 5.3 Relationship trace

```text
YOUR TRACE HERE

One Place saved · no confirmed visit
The Sorrento movement question is why Red Hook surfaced today.
```

This is descriptive. It must not say `A relationship in the making`, assign a
stage, or infer coastal preference.

### 5.4 Authorized human note

```text
MAYA · SHARED WITH YOU

“I use the ferry to arrive. I don't plan around it to get home.”

From a Red Hook note · shared [[DATE]] · audience: you
```

Design requirements:

- visually identify Maya as author and Vesper as neither author nor owner;
- make audience and source inspectable without dominating the note;
- no likes, reaction count, friend activity label, or `Ask Maya` action;
- remove the entire unit when may-use or may-name does not permit it;
- treat the wording as synthetic fixture content, not an actual statement by
  any real person.

### 5.5 Horizon doors

Show three typed paths:

```text
ACCESS
Why getting there changes the afternoon

TRANSFER
What Sorrento taught Vesper to separate here

ALTERNATIVE
Where the same waterfront intention has a more flexible edge
```

These are directional connections, not six editorial lens tabs.

### 5.6 Current possibilities

Show at most two concrete Place or event rows that fit the present scope.
Each needs one reason and one material burden. Example fixture structure:

```text
[[PLACE OR EVENT A]]
Works after the ferry arrival · 8 min walk · open through [[TIME]]

[[PLACE OR EVENT B]]
Better if the crossing slips · indoors · near the land return
```

Do not fabricate actual inventory for the design. Use named placeholders or
verified current fixtures.

### 5.7 Actions

At the end of the useful Place content:

```text
See Saturday's route
Ask Vesper about Red Hook
Add a Place to a plan
Share this bounded Place view
Correct your trace
```

The first action may be prominent. The others should be quiet doors. Value
must be complete before these actions appear.

## 6. Frame 3 — Place Path

### 6.1 Human posture

The person follows `Why getting there changes the afternoon` or the threshold
comparison from World Field.

The surface answers:

> **How does this connection work, what supports it, and what does it change
> here?**

### 6.2 First screenful

#### Origin and relation

```text
RED HOOK · ACCESS

TWO WATERFRONTS, TWO DIFFERENT THRESHOLDS

Sorrento's town and marina are close on a map but separated by elevation and
transfer. Red Hook is comparatively flat; its threshold is the continuity of
the network that reaches it.
```

This is the full relation statement. Do not title the screen `More like
Sorrento` or `Other cliffs around the world`.

#### Difference map

Use one paired spatial diagram:

```text
SORRENTO                         RED HOOK
town                             city network
  ↓ vertical transfer             → scheduled or indirect entry
marina                           harbor edge
  → regional ferry                ← flexible land return
```

The diagram must encode the important difference, not just show two maps next
to each other.

### 6.3 Substance

Use three concise distinctions:

```text
DISTANCE
Short physical distance can still conceal a hard transition.

DEPENDENCY
Sorrento's candidate constraint is vertical transfer and ferry sequence.
Red Hook's candidate constraint is network continuity and schedule.

FALLBACK
Saturday remains flexible only if the return does not depend on the same fixed
edge as the arrival.
```

These claims require the source apparatus below. If the evidence supports only
two distinctions, render two.

### 6.4 Evidence apparatus

Use a compact, inspectable source trail rather than a bibliography wall:

```text
WHY VESPER THINKS THIS

1 · Your Sorrento cliff and movement observations
2 · Hotel, marina, ferry, and corrected route Sources
3 · Current New York route and service truth
4 · Map geometry and access conditions

Analogy limit · one coastal threshold is vertical; the other is networked.
This does not make the Places culturally or experientially equivalent.
```

Selecting a source opens provenance without navigating away from the path.

### 6.5 Current consequence

```text
WHAT THIS CHANGES SATURDAY

Treat the crossing as an opening, not as the only viable return. That preserves
the waterfront character without making the day depend on one timetable.

Open the live interval →
```

This is the bridge from explanation to usefulness. It is not a prompt asking
whether the user agrees.

### 6.6 Honest next paths

Show at most two:

```text
Follow Red Hook's working-waterfront history
Compare a continuous-land waterfront route
```

Each must have a typed relationship and evidence. Remove either rather than
fall back to generic related content.

## 7. Frame 4 — Live Reduction

### 7.1 Human posture

The user enters from the Place Path or directly from Home's compact Saturday
proposition. The interval and dinner anchor are now material.

The surface answers:

> **What still works, what could break, and what is the stable next step?**

### 7.2 Entry continuity

When entered from Home, retain a small return label:

```text
From Home · Saturday waterfront interval
```

When entered from Place Path:

```text
From Red Hook · access threshold
```

This is navigational provenance, not a content card.

### 7.3 First screenful — operational instrument

```text
SATURDAY · 2:00–8:00 PM

THE WATERFRONT ROUTE STILL WORKS

Start on the scheduled edge. Return by land before dinner.

2:20  Depart [[ORIGIN]]
3:05  Reach Red Hook
3:05–6:50  Open waterfront interval
6:50  Begin flexible land return
7:40  Near dinner

Current as of [[TIME]] · no inventory held
```

Lead medium:

- route map and ordered sequence are synchronized views of one path;
- show end-near geometry and total movement burden;
- indicate fixed versus flexible segments without requiring a legend hunt.

### 7.4 Burden receipt

```text
WHAT THE ROUTE ASKS

Fixed       one scheduled departure
Walking     [[MINUTES]] · [[GRADE/ACCESS NOTE]]
Weather     [[CURRENT CONDITION + FRESHNESS]]
Return      flexible land branch
Dinner      [[MINUTES]] from the route end
```

This receipt is evidence, not a second action surface.

### 7.5 One fallback

```text
IF THE CROSSING STOPS FITTING

Keep the waterfront intention, drop the fixed edge.
Use the continuous-land branch and shorten the harbor interval.

[[ALTERNATIVE ROUTE SUMMARY]]
```

The fallback preserves the intent. Do not replace it with ten alternatives.

### 7.6 Temporal posture

Render exactly one posture when the facts justify it:

- `ACT NOW` — a real threshold is close and authority is sufficient;
- `HOLD` — the path works but commitment is not useful yet;
- `WAIT FOR SIGNAL` — one information event should resolve first;
- `MONITOR` — Vesper is authorized to watch a named condition; or
- `RELEASE` — the possibility no longer beats its burden.

Fixture default:

```text
HOLD
The route is viable. Nothing needs booking yet.
```

Do not turn `HOLD` into a task or ask the user to keep checking.

### 7.7 Action seam

```text
Use this route
Adjust in Chat
Open Red Hook
```

`Use this route` must preview what will be created or changed and who can see
it. It may create or modify a Plan only through the owning capability.

### 7.8 Suppressed material

The Live Reduction screen should not show:

- the long Sorrento comparison;
- a general article shelf;
- unrelated saved Places;
- a friend activity strip;
- relationship-stage language;
- multiple event rails; or
- retrospective trip content.

Those remain reachable through the focal Place or path, not repeated during
the live interval.

## 8. Component and composition inventory

This is a semantic inventory, not a final component API.

| Composition | Frame | Job | Correct containment posture |

| Lead + siblings | World Field | Establish hierarchy among Places | scale and orientation, not card elevation |
| Returned-understanding unit | World Field | Carry one useful distinction forward | editorial seam or uncarded path |
| Place identity | Place Focus | Establish focal Place | media or map is the object |
| One-Place verdict register | Place Focus | Say what to do with the Place now | uncarded unless it is an actual promoted offer |
| Relationship trace | Place Focus | State governed continuity | uncarded, compact |
| Attributed human note | Place Focus | Add bounded situated judgment | source-shaped, not social-feed card |
| Horizon doors | Place Focus | Open typed connections | rows or editorial seams |
| Difference map | Place Path | Show relation and analogy limit | diagram, border-only if grouping is needed |
| Evidence apparatus | Place Path | Support the claim | page-level provenance, uncarded |
| Current consequence | Place Path | Translate explanation into present value | editorial seam |
| Route instrument | Live Reduction | Make one path operationally legible | contained instrument |
| Burden receipt | Live Reduction | Expose proof and cost | inside the instrument or immediately subordinate |
| Fallback | Live Reduction | Preserve intent under failure | one clear alternate branch |
| Temporal posture | Live Reduction | End checking or trigger a justified next step | small status, never a gamified state |

## 9. Visual exploration freedom

The dedicated design tool should explore:

- whether the spatial field leads with map, annotated diagram, or hybrid;
- how selected Place identity persists between full-scroll screens;
- how the same route transforms between map and sequence;
- how the page tapers from full lead to compact doors;
- how human authorship and audience read without social-media chrome;
- how evidence expands without overwhelming the main contribution;
- how a diagram distinguishes Sorrento's vertical threshold from Red Hook's
  network threshold; and
- how Live Reduction becomes more operational without adopting a visually
  unrelated dashboard language.

The tool may redesign the corrected canvas's exact cards, crown, typography,
and section layout. It must preserve the semantic hierarchy and transitions.

## 10. Forbidden shortcuts

Do not:

- design one product grammar per tab or one Place face per permanent section;
- use a generic `For you` feed;
- open with `What are you in the mood for?`;
- repeat `Sorrento has cliffs` as insight;
- title the connection `Places like Sorrento`;
- infer `You love waterfronts`;
- show a Europe recap above the New York world;
- use a personality interpretation such as `You experience travel through
  transitions`;
- represent Maya through a friend-activity shelf;
- make map a separate, forgetful product;
- show six lens tabs;
- add content to make all screens equally long;
- show more than one dominant lead;
- make saving, reacting, reflecting, or answering necessary to receive value;
- imply ferry, restaurant, event, or booking inventory is held;
- silently create a Plan; or
- let visual novelty obscure source, freshness, uncertainty, or burden.

## 11. Evaluation script

Test the board with these tasks, without explaining the internal model first.

### Task A — ordinary entry

Ask: `You opened Places without a question. What did it give you?`

Pass:

- the tester describes one New York possibility and its access structure;
- they do not call it a recommendation feed or trip recap; and
- they can identify why Red Hook differs from the other branches.

### Task B — select the Place

Ask: `Open Red Hook. What changed?`

Pass:

- selection preserves the New York scope and originating proposition;
- the screen becomes deeper rather than simply longer; and
- current truth, personal trace, and Maya's note remain distinguishable.

### Task C — follow the connection

Ask: `What did Sorrento add that you had not already said?`

Pass:

- the tester states the vertical-versus-network threshold distinction;
- they can name where the analogy breaks; and
- they do not interpret it as a preference or personality diagnosis.

### Task D — make it live

Ask: `It is Saturday. What should you do next, and what could break?`

Pass:

- one path, one burden receipt, and one fallback are obvious;
- current facts and freshness are visible;
- the tester knows whether anything has been booked or saved; and
- the screen feels like a reduced state of Places, not a separate planner.

### Task E — return

Ask the tester to go back twice.

Pass:

- Place Focus and World Field retain selection, map viewport, and scroll
  position;
- the followed path is visibly remembered without becoming a badge; and
- Home entry returns to the originating Home proposition.

## 12. Board acceptance checklist

- [ ] Four complete full-scroll mobile screens are present.
- [ ] They use one continuous evidence world.
- [ ] Every screen provides complete value before any action.
- [ ] No screen begins with a reflection or preference prompt.
- [ ] World Field has one lead, three branches maximum, and a visible end.
- [ ] Place Focus composes identity, current read, relationship, human
      perspective, and horizons without making them five rigid modules.
- [ ] Place Path adds new substance and an analogy limit.
- [ ] Live Reduction shows one route, one receipt, one fallback, and one
      temporal posture.
- [ ] Map and composition views preserve selection and context.
- [ ] Home deep-linking preserves the exact proposition.
- [ ] Human authorship, use, naming, and audience are legible.
- [ ] Current facts expose freshness.
- [ ] Generated possibility is not presented as desire, commitment, or
      occurrence.
- [ ] The Europe trip contributes without owning the New York viewport.
- [ ] The visual design uses hierarchy and taper rather than uniform card
      weight.
- [ ] The final board can be evaluated without reading this brief.

## Compact standard

> **One New York world, one selected Place, one substantive path, and one
> live reduction—continuous enough to feel like a single product, restrained
> enough that every visible unit earns its place.**
