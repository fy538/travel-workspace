## Work package A — input pays immediately

Compose short, complete consumer sequences for:

- a ticket sent alone: useful interpretation and the permitted quiet retention;
- that same ticket attached to a question: answer without assuming durable intake;
- a photograph with an authored observation: substance before a compact receipt;
- “Keep jazz in mind for Saturday”: optional intention without a naming wizard;
- a contextual change from a visible place or arrangement;
- an ordinary expense question versus an explicit shared-cost instruction.

Resolve the human job from wording and affordance, not medium alone. Never expose
Ask/Bring/Point as a classification quiz. Show pending processing, usable partial
results, and a recoverable failure for one ingestion case. Do not create a manual
filing queue or demand another contribution to justify the first.

## Work package B — refer to things cheaply

When arriving from Home, Places, Life, or an entity, show enough context for the
person to know what they are addressing. Exercise “later,” “not this place,”
“make it less rushed,” and a local correction. Ambiguous scope should be resolved
only when needed, not with a permanent ontology selector.

Direct and language changes act on the same owner. Show localized readback and
return to the originating surface. Navigation must not Undo an applied change;
Undo must not merely dismiss the message. Keep changes inspectable without
requiring everyone to operate a history or permissions screen.

## Work package C — leave and return without transcript archaeology

Show a person discussing unrelated topics, then returning to Saturday's current
arrangement. The current state must be accessible without searching old versions
or asking what was accepted. Explore the card-to-current-view seam alongside the
interaction project. Do not claim the card itself is a new durable source.

For shared participation, use the existing Invitation/Decision/Brief family.
The current arrangement may be a projection, not another group chat or a required
named Plan. Do not independently design membership or Occasion semantics.

## Work package D — fulfill a content opening

Reconcile Home-originated substantive content with the editorial family. Show one
complete reading/comparison, an optional contextual question about it, and its
return/Keep behavior. Home must already have delivered value; Chat should not be
the toll required to obtain the interesting part. Do not expand this into a new
generative-canvas or media-renderer research program.

Distinguish keeping an exact editorial composition from retaining a place or
intention. Do not automatically promote transient output into Life. If the
existing editorial-only Keep rule obstructs a desired behavior, name the narrow
conflict rather than adding a universal Save button.
