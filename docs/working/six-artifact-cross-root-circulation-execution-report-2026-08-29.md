# Six-Artifact Cross-Root Circulation — Execution Report

## Result

The A01–A06 portfolio is executable at fixture-contract altitude. Every case:

- compiles from an agent-facing semantic draft into one renderer-neutral
  `CompositionBriefV0`;
- has claim-local Sources, novelty posture, audience, authority, lifecycle,
  complete fallback, one lead medium, and at most one support;
- keeps one composition identity through Home, Chat, Places, and Life;
- changes medium, density, action posture, and persistence by root without
  copying canonical truth; and
- retains inspectable correction, withdrawal, invalidation, or expiry behavior.

This is not production agent generation, backend schema, durable storage,
native rendering, or release proof.

## 1. Completed artifact portfolio

| ID | Contribution that clears the threshold | Lead / support | Primary lifecycle proof |
| --- | --- | --- | --- |
| **A01** | Aeneas had become part of Augustan political genealogy before the later Flavian Colosseum | prose / evidence | Ephemeral until explicit save; exact frozen version and claim-local invalidation |
| **A02** | Rome and Maya's Paris trace differ in where the day allowed relief, not merely in city or simultaneous travel | comparison / sequence | Named authors, bounded trace precision, addressed audience, and partial withdrawal |
| **A03** | Four destination names conceal a threshold sequence with an explicit Amalfi-to-Naples gap | sequence / spatial | Saved reconstruction version 1 remains frozen when later evidence creates version 2 |
| **A04** | The cliff becomes a geological and urban mechanism: the documented lift functions as part of the town-to-marina network | evidence / spatial | Known observation does not satisfy novelty; unsaved expression remains recomputable from governed Sources |
| **A05** | A ferry arrival plus flexible land return makes one current Red Hook interval usable | spatial / comparison | Ephemeral current opening; Home selection and Source expiry remain separate from durable Place/Sources |
| **A06** | One leave threshold, route, heat posture, and fallback reduce current effort | instrument / sequence | Live UI expires; owner truth persists; receipt requires confirmed consequence |

All people, traces, tickets, schedules, and operational values remain labeled
fixture evidence unless backed by an authorized production Source. Maya's
contributions do not claim that a real friend supplied the represented content.

## 2. Lifecycle and authority results

### A02 — social withdrawal

The saved addressed composition retains the exact audience and author roles.
Withdrawing `maya-paris-relief-note`:

- affects only `maya-paris-alternation` and
  `relief-topology-comparison`;
- leaves the viewer's independent Rome claim and Sources intact;
- marks the saved expression `requires_revision`; and
- never turns the private original, relationship, or co-presence into authority
  to reconstruct Maya's exact itinerary.

### A03 — later evidence and revision

Version 1 keeps the Amalfi-to-Naples segment unresolved. A later fixture car
receipt compiles a new brief and produces version 2 with:

- the same saved-composition identity;
- an incremented version;
- a required human-readable revision reason;
- a dependency manifest containing the new Source; and
- a pointer to version 1 rather than an in-place rewrite.

### A04 — curiosity without repetition or diagnosis

The viewer's “Sorrento has cliffs” note is explicitly `known_to_person`. The
artifact earns admission through two additions:

1. a sourced description of the layered tuff-cliff condition; and
2. a bounded synthesis from the lift receipt and ferry ticket: vertical
   circulation functioned as part of the documented movement network.

It does not infer that the person prefers transitions, cliffs, ferries, or any
travel identity.

## 3. Cross-root circulation

The executable contract is in
`travel-app/utils/artifactCirculation.ts`. Every projection names the same
artifact identity, authorized represented Resources, complete on-view value,
root-native medium, actions, persistence posture, and a context-preserving
return envelope.

| Artifact | Home | Chat | Places | Life |
| --- | --- | --- | --- | --- |
| **A01** | Conditional compact claim | Inspect, challenge, correct, save | Separate Rome sites and periods | Exact snapshot only if saved |
| **A02** | Conditional attributed contrast | Remove either contribution or prepare addressed save | Coarse intervals only; exact trace withheld | Relationship-scoped snapshot and audience epoch |
| **A03** | Suppressed unless one threshold matters now | Resolve gap, correct, exclude, save | Planned, evidenced, unresolved segments | Journey, Sources, gaps, saved version lineage |
| **A04** | Conditional practical opening | Inspect mechanism or remove evidence | Town, cliff, lift, marina, ferry | Source continuity; unsaved expression recomputes |
| **A05** | Current compact possibility | Adjust time, radius, effort, companions | Own current route and reachability depth | Prior Sources and Place continuity, not regenerated rankings |
| **A06** | Current operational threshold | Alter, authorize, or repair | Route, heat, entrance, fallback | Owner outcome or confirmed receipt only |

The compiler rejects:

- a copied root-specific identity;
- missing Home, Chat, Places, or Life projection;
- Resources absent from the brief manifest;
- Home density or action-budget violations;
- Chat without inspection and correction;
- Places depth without a named spatial reason;
- Life persistence inconsistent with ephemeral, saveable, or live lifecycle;
  and
- cross-root transitions without a return envelope.

## 4. Provisional semantic contracts demonstrated

The portfolio derives seven repeated semantic needs. These are provisional
contracts, not seven required visual components and not a universal card API.

| Semantic need | Contract |
| --- | --- |
| **Evidence apparatus** | Bind displayed claims to inspectable Source roles and correction effects. |
| **Attributed contribution** | Preserve human author, audience, precision, expiry, and withdrawal inside the object changed. |
| **Ordered sequence** | Represent order, thresholds, gaps, and current state without fabricating continuity. |
| **Bounded comparison** | Use one honest common axis, preserve asymmetry, and state the analogy limit. |
| **Spatial reference** | Retain stable Place identity and a complete nonvisual alternative while the root owns geometry. |
| **Continuation control** | Expose only actions authorized for the current root and preserve a return envelope. |
| **Lifecycle notice** | Make ephemeral, saveable, saved, shared, live, stale, corrected, and withdrawn state legible. |

Each contract is emitted only when at least two portfolio artifacts demonstrate
the need. Article, guide, reconstruction, and social juxtaposition remain
formats or assemblies. Social and relational remain modifiers. Home, Chat,
Places, and Life remain postures. None becomes a component superclass.

## 6. What this authorizes next

The portfolio now contains enough evidence to design a **native semantic
renderer lab** around the seven demonstrated contracts. The next implementation
should render A01–A06 at compact, standard, and immersive density using root
ownership, then evaluate comprehension, provenance, authorship, action clarity,
large type, reduced motion, offline/stale state, and correction.

It does not yet authorize:

- a universal `ArtifactCard` prop matrix;
- agent-authored component trees;
- production persistence or a generic artifact-write endpoint;
- a cross-root visual clone;
- automatic social sharing; or
- replacing existing owner APIs with the fixture score or reason vocabulary.
