# Ruling needed: the Returns layer

> **RESOLVED 2026-08-31 — Option B adopted**, via
> `life-anchors-fresh-design-audit-and-correction-brief-2026-08-30.md`
> §3.3, with tighter language: one bounded `RETURNS` region, 0–3 rows,
> only the five accepted classes, material reason inline, suppressible
> as a layer, never filled to quota, never rotated for freshness. The
> region changes only when time, evidence, authority, explicit
> direction, or the referenced world materially changes. Execution is
> gated behind the Return Anatomy Lab (§17.6): design the return
> itself before the shelf. The secondary RESTING-in-digest question is
> superseded by the brief's Threads correction (§4.3): OPEN/RESTING/
> CLOSED is demoted as the dominant user-facing lifecycle.

## The contradiction

Two of your own rulings disagree:

- **The fixed-windows law** (2026-08-30, design phase): Life's page
  changes only when time, the record, or authority changes — never per
  visit, never for engagement. Reflections are keepsake + specimen only;
  the old RETURNS section was retired; prose reflections and rotation are
  do-not-resurrect.
- **The Life continuity decision §8.2** (2026-08-29, adopted): Life's
  entrance carries "a small, finite set of **earned adaptive
  entrances**" — `Continue where you left off` · `Newly useful` ·
  `Recently completed` · `From someone you know` · `Worth returning to`
  — including returns triggered by a **changed world condition** (a
  dormant intention made newly possible), and the person may **suppress
  the adaptive layer as a layer** while keeping search and stable access.

The design deleted a layer the adopted decision requires. Three of its
five entrance types (`Newly useful`, `From someone you know`, `Continue`)
have no seat anywhere in the current anatomy — the keepsake is a real
artifact and the specimen is existing scroll material; neither can carry
a composition, an addressed Together return, or a world-condition
trigger.

## Option A — Keep the strict law; amend the continuity decision

Life stays fully fixed. `Continue` lives in Chat; `Newly useful` and
`From someone you know` become Home's problem (Home already owns timely
value). Amend §8.2 down to search + stable doors.

- For: purest archive identity; zero recommender risk; nothing to tune.
- Against: Home's admission bar ("beats silence *now*") will drop most
  of these returns on the floor — a friend's addressed juxtaposition or
  a newly-possible dormant intention often isn't urgent, just newly
  alive. They end up homeless. Also amputates the loop's return path
  (Life → openings) that you called the elegant part.

## Option B — One bounded RETURNS region, reconciled to the law (recommended)

Add back exactly one region between the scroll door and the
reflections: `RETURNS`, 0–3 rows, each an **earned** entrance of the
five decision types, each carrying its reason inline ("newly useful —
the ferry runs again"), suppressible as a layer, empty = absent.

The reconciliation: a changed world condition **is** the world-record
changing — the ferry schedule resumed, a friend addressed something to
you, a thread you left gained a missing piece. None of that is
engagement scheduling; the region still never changes *per visit*, still
never rotates for freshness. The fixed law survives intact — restated as
"changes only when time, the record, authority, **or the world it
references** changes."

- For: honors both rulings; gives the loop its return seats; the reason-
  inline requirement keeps it inspectable; layer-suppression control
  satisfies the research's resurfacing-rights findings.
- Against: it is the most recommender-shaped thing on the page; needs
  discipline (0–3, earned, reasons visible) to not become a feed.

## Option C — Fold returns into the existing slots

Let the specimen slot accept `Newly useful` items and windows accept
`From someone you know`. No new region.

- For: no anatomy change.
- Against: quietly corrupts three clean definitions (specimen = hidden
  in scroll; windows = fixed cross-lens; keepsake = artifact). The
  auditors would flag it next sweep, correctly.

## A second, smaller ruling while you're here

**Resting/dormant items in the digest.** The continuity decision (§6)
defaults undated `someday` intentions to search/context-only; our
Threads digest shows them under `RESTING · THEY WILL KEEP`. Options:
keep RESTING in the digest (it's quiet, non-nagging, and honest about
the corpus) **[recommended — but record it as a deliberate deviation]**,
or move resting behind the scroll door and let the statline carry the
count only.

## What happens after you rule

Option B → I design the RETURNS region (one board + the Time page worn
with it), amend the spec, and the fixed-windows law gets its final
wording. Option A → I amend the continuity decision instead. Either way
the contradiction closes.
