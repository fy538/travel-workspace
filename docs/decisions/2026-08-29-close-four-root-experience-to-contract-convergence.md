# Close Four-Root Experience-to-Contract Convergence

## Decision

Accept the five-situation integrated semantic portfolio as the upstream
experience requirement for Home, Chat, Places, and Life. Accept its minimum
projection, field-to-owner, semantic result, return-envelope, and bounded-read
contracts as the next architecture seam.

Accept the current implementation only as a **dark contract and native
semantic lab package**:

- the backend semantic facade remains default-off and now uses Composition,
  not Artifact, for generated primary projection;
- its owner-read plan is limited to capabilities demonstrated by the selected
  portfolio and does not serve new tools or create a Monitor owner;
- the frontend result envelope and four-root portfolio are fixture-only;
- the native lab proves semantic completeness and state coverage, not final
  visual quality;
- the Home/Chat/Places/Life shell is internal-only, default-off, and maps to
  existing compatibility routes; and
- no public API, generated mobile contract, database owner, production writer,
  or user-visible default changes in this decision.

## Vocabulary ruling

- **Artifact:** a human-facing thing brought, captured, received, or made;
- **Source:** the evidentiary and custody role through which material supports a
  Claim;
- **Claim:** a bounded assertion with evidence, authority, time, audience, and
  correction;
- **Composition:** a Vesper-generated or assembled return;
- **Saved Composition:** an explicitly retained version and dependency
  manifest;
- **Instrument:** a stateful expression of current truth or consequence;
- **Direct State:** owner truth expressed without generated ceremony; and
- **Projection:** a viewer-, root-, density-, and moment-relative rendering.

Existing implementation types named Canonical Artifact or Atlas Artifact are
legacy compatibility contracts, not permission to collapse these nouns again.

## Evidence accepted

- one semantic portfolio covers ordinary New York, emerging Saturday, live
  disruption, Europe return, and social withdrawal across all four roots;
- Home and Places return value without required response;
- Chat can remain empty, answer directly, operate, repair, or stop;
- Life supports re-finding and governed continuity without curation homework;
- urgent Home reduces to one Instrument;
- social value is integrated into another object or consequence;
- withdrawal and unknown state are explicit; and
- one identity and return context survive root movement.

## Promotion withheld

The following remain deliberately unaccepted:

1. a final visual system—the dedicated-tool A/B/C comparison and founder
   selection are still pending;
2. actual owner-read adapters beyond the existing truthful compatibility
   catalog;
3. a public semantic result or projection API;
4. production Home, Chat, Places, or Life surface conformance;
5. consequence, repair, and multiplayer behavior beyond existing owners and
   fixture contracts;
6. a durable generalized Monitor owner; and
7. dogfood or behavioral product-proof claims.

## Next authorized package

The next implementation package may begin only after visual selection. It may:

- render the selected portfolio with native components in the lab;
- implement the minimum existing-owner adapters used by those frames;
- introduce a generated API contract if the semantic envelope crosses the
  network; and
- evaluate the internal shell through complete cross-root handoffs.

Production promotion requires native visual evidence, owner readback,
correction and revocation behavior, accessible degraded states, and a separate
founder decision.
